# Create an issue

1. Reuse an existing issue for the task when one is supplied or found in the repository.
2. Otherwise, fill in [the task issue template](../../../.github/ISSUE_TEMPLATE/task.md) and create the issue in `Sanoma-AI/sanoma` with a concise title. With `gh`, pass the completed body via `--body-file`.
3. Return the issue number and URL for the task branch or PR to reference.
