# connectors/github/test

Tests for the GitHub connector. They run on the replies recorded in `sanoma/internal/bridge`'s `testdata` and GitHub's GraphQL and REST replies in `fixtures/`, with no token and no network.

## Contents

| Path                                     | What it is                                                                                                                                                                                                                                                                                                                  |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`agent.test.ts`](agent.test.ts)         | Copilot, the agent part, as the app and the runtime read it                                                                                                                                                                                                                                                                 |
| [`resources.test.ts`](resources.test.ts) | The generated types parse the recorded reads; the operations, identities and comparison                                                                                                                                                                                                                                     |
| [`change.test.ts`](change.test.ts)       | The change operations over replayed plans and applies (synthetic, in the provider's shape): a repository created, updated and deleted; a deploy key created and deleted, every field a replace; a collaborator invited, re-invited for a new permission (a replace) and withdrawn                                           |
| [`driver.test.ts`](driver.test.ts)       | `githubDriver` over a `stateBridge`: import, read, configuration (a new token, the owner each call names, a second owner, concurrent calls, a forgotten provider), a call naming no owner or two, errors, `gone`, the default bridge and the declared variables; `fakeGithub`                                               |
| [`node.test.ts`](node.test.ts)           | A node id (a binding id) given to `import`: resolved to its owner and import id by one GraphQL query, replayed from `fixtures/` (`sanoma/testing/replay`; hand-written in the recorded shape until recorded live), and by the fake with none                                                                                |
| [`app.test.ts`](app.test.ts)             | The operations through the App over replayed replies (`fixtures/app-*.json`, hand-written in GitHub's shape; skipped live): an installation, a repository generated (GitHub's 403, 422), a commit on a branch and a new one, a branch's head (an empty repository's 409 tried again), a deploy key; `fakeGithubApp`         |
| [`app-keys.ts`](app-keys.ts)             | The App's test keys, `signer` (the App a JWT is signed by) and `scrub` (no minted token in a recording), for `app.test.ts` and `remote.test.ts`                                                                                                                                                                             |
| [`remote.test.ts`](remote.test.ts)       | `githubRemote` over replayed replies (`fixtures/remote-*.json`, GitHub's own; writes hand-written): `matches`, each `SourceHost` method (a merge's 409 and 405), `enforcement` on a ruleset and on Free's 403, the token order (the App's installation token, `GITHUB_TOKEN`), the webhooks' signature and events, `owners` |
