# connectors/github/src

Source of the GitHub connector: the resource types, generated from the OpenTofu provider's schema and finished by hand, the operations, the driver that reads through the provider bridge, and a fake over recorded replies, all from one `tfConnector` record.

## Contents

| Path                                         | What it is                                                                                                                                                                                          |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`connector.ts`](connector.ts)               | `githubTf`: the `tfConnector` record: each generated type's title, identity, `find` and `bindingId` (the vendor's title and logo are in `package.json`)                                             |
| [`index.ts`](index.ts)                       | The package root: the `github` connector (each resource type's `read` and `import`) with its driver and fake attached (`withSetup`)                                                                 |
| [`resources.ts`](resources.ts)               | The data-file constructors, `github.<type>(...)`                                                                                                                                                    |
| [`resources.gen.ts`](resources.gen.ts)       | Generated by `pnpm generate`: each type's zod schema, flagged fields and state layout                                                                                                               |
| [`resources.config.ts`](resources.config.ts) | Hand-owned input to `pnpm generate`: the provider, the types, the immutable attributes                                                                                                              |
| [`driver.ts`](driver.ts)                     | `githubDriver`: the record's driver over the default bridge (or one given), with the token and the owner read from the environment on every call, and a node id resolved to an import id by GraphQL |
| [`fake.ts`](fake.ts)                         | `fakeGithub`: the driver over the recorded replies (`tfFake`), with `put`, `override` and `remove` to simulate drift                                                                                |
