# connectors/github/src

Source of the GitHub connector: the resource types, generated from the OpenTofu provider's schema and finished by hand, the operations, the driver that reads through the provider bridge, and a fake over recorded replies, all from one `tfConnector` record; and the operations through Sanoma's GitHub App, over REST.

## Contents

| Path                                         | What it is                                                                                                                                                                                                                                                                                            |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`connector.ts`](connector.ts)               | `githubTf`: the `tfConnector` record: each generated type's title, identity, `find` and `bindingId`, and the fields that name a repository; `githubApp`, the operations through the App (`installation.get`, `repository.generate`, `.commit`, `.addDeployKey`); `githubOps`, both in one connector   |
| [`index.ts`](index.ts)                       | The package root: the `github` connector (`githubOps`: each resource type's operations and those through the App) with its driver, fake and remote half attached (`withSetup`)                                                                                                                        |
| [`resources.ts`](resources.ts)               | The data-file constructors, `github.<type>(...)`                                                                                                                                                                                                                                                      |
| [`resources.gen.ts`](resources.gen.ts)       | Generated by `pnpm generate`: each type's zod schema, flagged fields and state layout                                                                                                                                                                                                                 |
| [`resources.config.ts`](resources.config.ts) | Hand-owned input to `pnpm generate`: the provider, the types, the immutable attributes                                                                                                                                                                                                                |
| [`driver.ts`](driver.ts)                     | `githubDriver`: `owned` over a provider driver per owner on the default bridge (or one given), the token read from the environment on every call, and a node id resolved to its owner and import id by GraphQL; `appDriver`, the operations through the App, on an installation token minted per call |
| [`owner.ts`](owner.ts)                       | `owned`: a driver whose calls name their owner (a declaration's `owner`, `<owner>/` in a name), the provider configured for it and given names without it; the driver and the fake both use it                                                                                                        |
| [`remote.ts`](remote.ts)                     | `githubRemote`: the remote half (a repository's pull requests, the `sanoma` status, the rules on a branch, the App's webhooks and installations) over REST with `fetch`; `githubToken` (the App's installation token, else `GITHUB_TOKEN`), `appJwt`, `GITHUB_APP_SECRETS`                            |
| [`rest.ts`](rest.ts)                         | GitHub's REST API over `fetch` (`send`, `ok`, `failed` with GitHub's message), `appJwt`, `installationToken`, `GITHUB_APP_SECRETS`: shared by the remote half and the operations through the App                                                                                                      |
| [`fake.ts`](fake.ts)                         | `fakeGithub`: the driver over the recorded replies (`tfFake`), with `put`, `override` and `remove` to simulate drift, and `app` (`fakeGithubApp`), an in-memory GitHub for the operations through the App                                                                                             |
