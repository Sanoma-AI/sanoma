# connectors/github/src

Source of the GitHub connector: the resource types, generated from the OpenTofu provider's schema and finished by hand, the operations, the driver that reads through the provider bridge, and a fake over recorded replies.

## Contents

| Path                                         | What it is                                                                                  |
| -------------------------------------------- | ------------------------------------------------------------------------------------------- |
| [`index.ts`](index.ts)                       | Defines the `github` connector: each resource type's `read` and `import`, and the logo      |
| [`resources.ts`](resources.ts)               | The resource types (`defineResource`): identity and comparison; the data-file constructors  |
| [`resources.gen.ts`](resources.gen.ts)       | Generated by `pnpm generate`: each type's zod schema, flagged fields and state layout       |
| [`resources.config.ts`](resources.config.ts) | Hand-owned input to `pnpm generate`: the types, the release's pin, the immutable attributes |
| [`driver.ts`](driver.ts)                     | `githubDriver`: configures the provider, imports and reads, maps the bridge's errors        |
| [`bridge.ts`](bridge.ts)                     | `BridgeLike` and a replay of recorded replies, until `@sanoma/bridge` replaces them         |
| [`fake.ts`](fake.ts)                         | `fakeGithub`: the driver over the replay, with `override` and `remove` to simulate drift    |
