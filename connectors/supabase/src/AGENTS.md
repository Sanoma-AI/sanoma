# connectors/supabase/src

Source of the Supabase connector: the project type, generated from the OpenTofu provider's schema and finished by hand, its operations, the driver that reads through the provider bridge, and a fake over replies, all from one `tfConnector` record.

## Contents

| Path                                         | What it is                                                                                                                                     |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| [`connector.ts`](connector.ts)               | `supabaseTf`: the `tfConnector` record: the project type's title (no identity: bound by its ref) and `exists`, and the vendor's title and logo |
| [`index.ts`](index.ts)                       | The package root: the `supabase` connector (`project.read` and `project.import`) with its driver and fake attached (`withSetup`)               |
| [`resources.ts`](resources.ts)               | The data-file constructor, `supabase.project(...)`                                                                                             |
| [`resources.gen.ts`](resources.gen.ts)       | Generated by `pnpm generate`: the type's zod schema, flagged fields and state layout                                                           |
| [`resources.config.ts`](resources.config.ts) | Hand-owned input to `pnpm generate`: the provider, the type, the immutable attributes                                                          |
| [`driver.ts`](driver.ts)                     | `supabaseDriver`: the record's driver over the default bridge (or one given), with the token read from the environment on every call           |
| [`fake.ts`](fake.ts)                         | `fakeSupabase`: the driver over the replies (`tfFake`), with `put`, `override` and `remove` to simulate drift                                  |
