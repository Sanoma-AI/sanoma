# connectors/supabase/src

Source of the Supabase connector: the project type, generated from the OpenTofu provider's schema and finished by hand, its operations, the driver that reads and changes projects through the provider bridge, the Management API operations beside them, and a fake over replies.

## Contents

| Path                                         | What it is                                                                                                                                                                                                                                   |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`connector.ts`](connector.ts)               | `supabaseTf`: the `tfConnector` record: the project type's title (no identity: bound by its ref), `exists` and `writable` (the vendor's title and logo are in `package.json`); `supabaseOps`, it with the Management API operations' schemas |
| [`management.ts`](management.ts)             | `withManagement`: a driver with `pooler.get`, `project.health`, `database.storeUrl` and the create guard over a `ManagementApi`, and the URL's secret name                                                                                   |
| [`index.ts`](index.ts)                       | The package root: the `supabase` connector (`supabaseOps`) with its driver and fake attached (`withSetup`)                                                                                                                                   |
| [`resources.ts`](resources.ts)               | The data-file constructor, `supabase.project(...)`                                                                                                                                                                                           |
| [`resources.gen.ts`](resources.gen.ts)       | Generated by `pnpm generate`: the type's zod schema, flagged fields and state layout                                                                                                                                                         |
| [`resources.config.ts`](resources.config.ts) | Hand-owned input to `pnpm generate`: the provider, the type, the immutable attributes                                                                                                                                                        |
| [`driver.ts`](driver.ts)                     | `supabaseDriver`: the record's driver over the default bridge (or one given) with the Management API over `fetch`, the token read on every call                                                                                              |
| [`fake.ts`](fake.ts)                         | `fakeSupabase`: the driver over the replies (`tfFake`), its Management API answered from the same projects, with `put`, `override` and `remove`                                                                                              |
