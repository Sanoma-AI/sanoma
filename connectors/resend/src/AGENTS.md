# connectors/resend/src

Source of the Resend connector: the operation definitions, the driver that calls Resend, and an in-memory fake for tests.

## Contents

| Path                           | What it is                                                                                                                                   |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| [`generated/`](generated/)     | Hey API client for the three Broadcasts operations and `POST /emails`, generated by `pnpm run generate`                                      |
| [`connector.ts`](connector.ts) | Defines `resendOps`, the `resend` connector's operations: `broadcast.create`, `broadcast.send` and `emails.send`, their schemas and the logo |
| [`index.ts`](index.ts)         | The package root: `resend` with its driver, fake and steps attached (`withSetup`)                                                            |
| [`driver.ts`](driver.ts)       | `resendDriver`: calls Resend through the generated client and maps failures to `DriverError`                                                 |
| [`fake.ts`](fake.ts)           | `fakeResend`: an in-memory Resend for tests that emails nothing                                                                              |
| [`steps.ts`](steps.ts)         | `resendSteps`: Resend's steps for Gherkin tests (`defineSteps`)                                                                              |
