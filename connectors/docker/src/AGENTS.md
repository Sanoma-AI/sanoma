# connectors/docker/src

Source of the Docker connector: `docker.container`, a host mapped onto the provider's `docker_container`, its driver over the provider bridge and Docker's inspect, and a fake.

## Contents

| Path                                         | What it is                                                                                                                                                       |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`connector.ts`](connector.ts)               | `dockerTf`: the `tfConnector` record, the container type (`TfMapped`: schema, `toProvider`, `fromProvider`), its host spec, `LABELS`, `CREATE_ONLY`; `dockerOps` |
| [`index.ts`](index.ts)                       | The package root: the `docker` connector with its driver and fake attached (`withSetup`)                                                                         |
| [`resources.ts`](resources.ts)               | The data-file constructor, `docker.container(...)`                                                                                                               |
| [`resources.gen.ts`](resources.gen.ts)       | Generated by `pnpm generate`: `docker_container`'s zod schema, flagged fields and state layout                                                                   |
| [`resources.config.ts`](resources.config.ts) | Hand-owned input to `pnpm generate`: the provider, the type, its ForceNew attributes                                                                             |
| [`driver.ts`](driver.ts)                     | `dockerDriver`, `dockerHost` (the daemon's address), `inspectContainer` and `observed` (an imported state completed from Docker's inspect)                       |
| [`fake.ts`](fake.ts)                         | `fakeDocker`: the driver over a `stateBridge` of the recorded replies                                                                                            |
