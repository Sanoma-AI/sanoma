# connectors/stripe/src

Source of the Stripe connector: the resource types, generated from the OpenTofu provider's schema and finished by hand, the operations, the driver that reads through the provider bridge, and a fake over replies, all from one `tfConnector` record.

## Contents

| Path                                         | What it is                                                                                                                             |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| [`connector.ts`](connector.ts)               | `stripeTf`: the `tfConnector` record: each generated type's title (no identity: bound by Stripe's id), and the vendor's title and logo |
| [`index.ts`](index.ts)                       | The package root: the `stripe` connector (each resource type's `read` and `import`) with its driver and fake attached (`withSetup`)    |
| [`resources.ts`](resources.ts)               | The data-file constructors, `stripe.<type>(...)`                                                                                       |
| [`resources.gen.ts`](resources.gen.ts)       | Generated by `pnpm generate`: each type's zod schema, flagged fields and state layout                                                  |
| [`resources.config.ts`](resources.config.ts) | Hand-owned input to `pnpm generate`: the provider, the types, the immutable attributes                                                 |
| [`driver.ts`](driver.ts)                     | `stripeDriver`: the record's driver over the default bridge (or one given), with the key read from the environment on every call       |
| [`fake.ts`](fake.ts)                         | `fakeStripe`: the driver over the recorded replies (`tfFake`), with `put`, `override` and `remove` to simulate drift                   |
