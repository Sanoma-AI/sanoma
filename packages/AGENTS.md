# packages

The workspace packages that make up Sanoma's core: `sanoma`, the one package a company installs (the runtime, the app, the bridge, the test helpers, `sanoma dev` and Better Auth are its parts), the platform binaries it installs, and the private packages. Vendor connectors live in `connectors/`.

## Contents

| Path                                      | What it is                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`bridge-bin/`](bridge-bin/AGENTS.md)     | `@sanoma-ai/bridge-<platform>`: the provider-bridge binary for each platform, downloaded at pack time                                                                                                                                                                                                                                                                                                                                                                                       |
| [`desktop/`](desktop/AGENTS.md)           | `@sanoma-ai/desktop` (private): the desktop shell, which runs a company folder's own launcher and shows the app in a window                                                                                                                                                                                                                                                                                                                                                                 |
| [`invoices/`](invoices/AGENTS.md)         | `@sanoma-ai/invoices` (private): shared invoice validation, exact calculations, industry adapters and React PDF rendering                                                                                                                                                                                                                                                                                                                                                                   |
| [`postgres-bin/`](postgres-bin/AGENTS.md) | `@sanoma-ai/postgres-<platform>`: the PostgreSQL 18 server for each platform, filled at pack time from zonky's jars                                                                                                                                                                                                                                                                                                                                                                         |
| [`sanoma/`](sanoma/AGENTS.md)             | `sanoma`: the bin a company repo runs, checks and exports itself with, the surface its workflows import, and its parts: [`workflows/`](sanoma/workflows/AGENTS.md) (`sanoma/workflows`), [`app/`](sanoma/app/AGENTS.md) (`sanoma/app`), [`bridge/`](sanoma/bridge/AGENTS.md) (`sanoma/internal/bridge`), [`testing/`](sanoma/testing/AGENTS.md) (`sanoma/testing`), [`dev/`](sanoma/dev/AGENTS.md) (`sanoma dev`) and [`better-auth/`](sanoma/better-auth/AGENTS.md) (`sanoma/better-auth`) |
