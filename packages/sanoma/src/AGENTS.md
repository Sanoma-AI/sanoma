# packages/sanoma/src

The source of `sanoma`: the bin (`cli.ts`, `dist/cli.js` once built) and the modules it is made of, and the package's entries, `index.ts` and `resources.ts` (`sanoma/resources`); `sanoma/site` and `sanoma/ui` are `../site.js` and `../ui.js`, outside `src/` (see the [package's guide](../AGENTS.md)).

## Contents

| Path                                   | What it is                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`cli.ts`](cli.ts)                     | The bin: `sanoma` (the sites on the dev server), `serve` (hidden: builds them; `--dev` for dev mode's child), `api` (hidden: writes `.sanoma/api.ts`), `worker`, `app`, `wakeup` (and `wakeup account`), `check`, `env`, `ledger export`, `--help`; signals, exit codes (a problem in the policies is a usage error but for `check`); each command imported when run                                                                                                                                                                                                                                                                                                               |
| [`check.ts`](check.ts)                 | `check`: the policies' problems (`policyProblems`, as `resolveConfig` reads them), the generated files (`writeGenerated`), then a site's files; tsc, oxlint on the repo's `.oxlintrc.json` (written when missing), `describeConfig`'s problems and the sites (the app built with them, a denied import at its line, `tsc -p sites/tsconfig.json`) at once, folders refused as sites, the content's problems (`readContent`), then `runScenarios`; one line each, and the sites' `warnings`, which never fail it                                                                                                                                                                    |
| [`config.ts`](config.ts)               | `loadConfig`: `.env`, then `sanoma.config.ts`'s default export, with its root, and the collections `resources/data.ts` exports; `UsageError`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| [`dev.ts`](dev.ts)                     | Dev mode: `linkedPackages` (the linked packages and the core packages reached through them, found by `module.findPackageJSON`), `devRepo`, `partialLink` (the core packages a partial link leaves installed), `supervise` (restart on a change under `dist/`, but for the directories it ignores), `whenUnlinked` (the repo no longer links the checkout: dev mode ends), `startWatchers` (each package's `watch`), `end` (a process group)                                                                                                                                                                                                                                        |
| [`events.ts`](events.ts)               | `emit`: with `SANOMA_EVENTS=1`, an event (`SanomaEvent`: `ready`, `error`, `database`, `checked`) as one JSON line on stdout for a parent process; `eventsOn`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

| [`init.ts`](init.ts)                   | `startCompany`: `sanoma` in an empty directory: the template, the package's name, its creator as the first person in `resources/people.ts` (`whoIsStarting`, `declareFounder`), `.env`, the install (`packageManagerOf`), the first commit                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| [`key.ts`](key.ts)                     | `addToEnv` (variables a `.env` lacks); `writeSecretsKey`, the one writer of `SANOMA_SECRETS_KEY` (`startCompany`'s too); `ensureSecretsKey`: one made when missing, before `serve` starts the worker                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| [`index.ts`](index.ts)                 | What a company repo imports: the names the lint lets a workflow import (`z` among them), `defineConfig`, the ledger stores, types; Node's types, by a preserved reference                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| [`oxlint-plugin.ts`](oxlint-plugin.ts) | The oxlint plugin `sanoma`: `@sanoma-ai/workflows/plugin`'s `data-file` and `date`, and `site-file`, for the generated `oxlint.json` to load from `dist/`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| [`ledger.ts`](ledger.ts)               | `exportLedger`: a run's records through a `SanomaClient`, as JSON lines                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| [`postgres.ts`](postgres.ts)           | `ensurePostgres`: a URL named probed and used as it is, else the company's own cluster in `.sanoma/postgres` of the main checkout (`clusterDir`): found running, started or made (`initdb`) under the `starting` lock, `pg_ctl` detached, its port moved when taken, stopped by the call that started it when no other client is connected; `masked`, `answers`                                                                                                                                                                                                                                                                                                                    |
| [`postgres-bin.ts`](postgres-bin.ts)   | `postgresBin`: `SANOMA_POSTGRES_DIR`, else the installed `@sanoma-ai/postgres-<platform>` package's archive, extracted once (system `tar`, temp dir renamed into place) into the OS's cache (`cacheDir`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| [`resources.ts`](resources.ts)         | The `sanoma/resources` entry, for data files: `secret` and `sanoma` (people, agents, groups)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

| [`source.ts`](source.ts)               | `localGitSource`: the repo's git checkout as the runtime's `Source`, committing on the current branch; its drafts, each a git worktree at `.sanoma/drafts/<id>` on `draft/<id>` with the root's `node_modules` linked in, listed by `git worktree list`; one git write at a time in the process                                                                                                                                                                                                                                                                                                                                                                                    |
