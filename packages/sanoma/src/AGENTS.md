# packages/sanoma/src

The source of `sanoma`: the bin (`cli.ts`, `dist/cli.js` once built) and the modules it is made of, and the package's entries, `index.ts` and `resources.ts` (`sanoma/resources`).

## Contents

| Path                                   | What it is                                                                                                                                                                                                                                                      |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`cli.ts`](cli.ts)                     | The bin: `sanoma`, `serve` (hidden), `worker`, `app`, `check`, `env`, `ledger export`, `--help`; signals, exit codes; each command imported when run                                                                                                            |
| [`check.ts`](check.ts)                 | `check`: tsc, oxlint on the repo's `.oxlintrc.json` (written when missing) and `describeConfig`'s problems at once, then `runScenarios` once Postgres is `ready`; one line each                                                                                 |
| [`config.ts`](config.ts)               | `loadConfig`: `.env`, then `sanoma.config.ts`'s default export, with its root; `UsageError`                                                                                                                                                                     |
| [`dev.ts`](dev.ts)                     | Dev mode: `linkedPackages`, `devRepo`, `partialLink` (the core packages a partial link leaves installed, found by `module.findPackageJSON`), `supervise` (restart on a change under `dist/`), `startWatchers` (each package's `watch`), `end` (a process group) |
| [`env.ts`](env.ts)                     | `renderEnvExample` and `writeEnvExample`: `.env.example` from the variables the drivers declare                                                                                                                                                                 |
| [`init.ts`](init.ts)                   | `startCompany`: `sanoma` in an empty directory: the template, the package's name, `.env`, the install (`packageManagerOf`), the first commit                                                                                                                    |
| [`key.ts`](key.ts)                     | `addToEnv` (variables a `.env` lacks); `writeSecretsKey`, the one writer of `SANOMA_SECRETS_KEY` (`startCompany`'s too); `ensureSecretsKey`: one made when missing, before `serve` starts the worker                                                            |
| [`index.ts`](index.ts)                 | What a company repo imports: the names the lint lets a workflow import (`z` among them), `defineConfig`, the ledger stores, types; Node's types, by a preserved reference                                                                                       |
| [`oxlint-plugin.ts`](oxlint-plugin.ts) | The data-file oxlint plugin, re-exported from `@sanoma-ai/workflows/plugin`, for the generated `oxlint.json` to load from `dist/`                                                                                                                               |
| [`ledger.ts`](ledger.ts)               | `exportLedger`: a run's records through a `SanomaClient`, as JSON lines                                                                                                                                                                                         |
| [`postgres.ts`](postgres.ts)           | `ensurePostgres`: probe the URL, else (on a loopback host, `isLoopback`) start or create `sanoma-<appName>-postgres` in Docker and wait for it; `masked`                                                                                                        |
| [`resources.ts`](resources.ts)         | The `sanoma/resources` entry, for data files: `secret`                                                                                                                                                                                                          |
| [`serve.ts`](serve.ts)                 | `runWorker`, `runApp`, `serve`: the worker (promoted) and the app, stoppable, each given the config's checkout as `source`; `appOptions`: the app's host and GitHub sign-in from the environment                                                                |
| [`source.ts`](source.ts)               | `localGitSource`: the repo's git checkout as the runtime's `Source`, committing on the current branch                                                                                                                                                           |
