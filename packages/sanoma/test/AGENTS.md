# packages/sanoma/test

Vitest tests for `sanoma`. `cli.test.ts`, `check.test.ts` and `postgres.test.ts` need Postgres (`pnpm db:up`), `embedded.test.ts` this platform's PostgreSQL 18 (`pnpm postgres:download`); `cli.test.ts` and `check.test.ts` run a copy of the fixture repo against the packages' builds, which `fixture.ts` makes when stale.
