# packages/sanoma/app/src/routes/connectors

The pages under `/connectors`: the list of the config's connectors (the company's own operations above them), the page for one connector, and the page for one of the company's operations.

## Contents

| Path                                           | What it is                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`$vendor.tsx`]($vendor.tsx)                   | `/connectors/:vendor`: named connection cards and secure account actions, links, resources, operation contracts/scenarios and workflow dependencies                                                                                                                                                                                                                                    |
| [`index.tsx`](index.tsx)                       | `/connectors`: Yours, the company's own operations (each with its id, effect, where it can run and what uses it, linking to its page), then Installed, every connector with how many operations it has, workflows use it and variables it needs, linking to its page; Available, the connector packages on npm not installed, each one's steps to add it in a sheet (`?add=<package>`) |
| [`operations.$name.tsx`](operations.$name.tsx) | `/connectors/operations/:name`: one of the company's own operations: where it can run and a link to Permissions, Takes and Returns, Calls (each linking to where it is shown), Code (its file from the root) and Used by                                                                                                                                                               |
| [`route.tsx`](route.tsx)                       | Layout for `/connectors`, with no component: sets the "Connectors" breadcrumb and page title                                                                                                                                                                                                                                                                                           |
