Sanoma runs a company's operations from one repository. Workflows are TypeScript functions that call vendors through connectors. Policies say who may start a workflow and which calls wait for approval. Every call is kept in a ledger.

These pages are for the people and agents who write that repository. They ship with the `sanoma` package, in `node_modules/sanoma/docs`, so the copy beside your code matches the version you run.
