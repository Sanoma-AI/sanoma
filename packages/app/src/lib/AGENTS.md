# packages/app/src/lib

Small helpers shared by components and graph code.

## Contents

| Path                             | What it is                                                                                                                                                                                                                                                                                                                                               |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`apply-plan.ts`](apply-plan.ts) | The change view's words and groups: `asApplyPlan` (an approval's details by shape), `rebindWords`, `plannedRows`, `shortId`, `STEP_GROUPS`                                                                                                                                                                                                               |
| [`cn-tables.ts`](cn-tables.ts)   | Class-merge tables generated by `cn build`                                                                                                                                                                                                                                                                                                               |
| [`decidable.ts`](decidable.ts)   | `decidableBy`: the approvals a person may decide, by the config's people (`mayDecide`)                                                                                                                                                                                                                                                                   |
| [`inbox.ts`](inbox.ts)           | The Inbox's approvals for its page: `useInbox`, `useDecided`, `usePending` (those you may decide too), `countByWorkflow`                                                                                                                                                                                                                                 |
| [`lines.ts`](lines.ts)           | Line numbers touched by a list of source spans, and a span's first and last line                                                                                                                                                                                                                                                                         |
| [`locales.ts`](locales.ts)       | A public site's languages as its pages' URLs say them (`virtual:sanoma/locales`, so the public host loads no `site.ts`): `siteOf`, `pageLocale` (the page's language, and whether its URL names one the site has) and `localesOf` (the page in each language, on this host)                                                                              |
| [`motion.ts`](motion.ts)         | `useReducedMotion` hook                                                                                                                                                                                                                                                                                                                                  |
| [`preview.ts`](preview.ts)       | The run form's will-ask line: `previewRequests` (a workflow's start and the operations it may call; the grid's rows too) and `willAsk` (the policy's answers as one line)                                                                                                                                                                                |
| [`records.ts`](records.ts)       | Between a run's graph and its ledger: `recordsFor` (a node's records) and `nodesByRecord`                                                                                                                                                                                                                                                                |
| [`sites.ts`](sites.ts)           | The company's sites for the Sites page, the bar and the crumbs: `useSites` (each site's title from its `site.ts`, by a root-relative glob, and its pages from the router, a page under `{-$locale}` in its default language), and a public site's own address (`publicAddress`, `usePublicAddress`): its domain, else `<name>.localhost` on this machine |
| [`time.ts`](time.ts)             | `utcText`: a time as UTC text, the same on server and browser                                                                                                                                                                                                                                                                                            |
| [`tone.ts`](tone.ts)             | Status-to-tone maps for runs, approvals, decisions and drift, and each tone's solid fill                                                                                                                                                                                                                                                                 |
| [`utils.ts`](utils.ts)           | `cn`, shadcn's class merger bound to the generated tables                                                                                                                                                                                                                                                                                                |
