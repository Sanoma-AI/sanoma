# packages/app/src/routes/workflows

The pages under `/workflows`: the overview, a table of the config's workflows or every run, and the page for one workflow.

## Contents

| Path                          | What it is                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`$name/`](%24name/AGENTS.md) | `/workflows/:name`: one workflow's page, its tabs Graph, Runs, Code and Scenarios, and its runs' pages                                                                                                                                                                                                                                                                                                                              |
| [`index.tsx`](index.tsx)      | `/workflows`: a row per workflow (how it starts, its vendors, its last run, what waits), `?filter=` picking them (waiting, failed last run, built-in), its count and New workflow in its header, pill tabs for the filters and All runs, a find box over the table (title or name, in the browser), those waiting on you first with a waiting pill; or `?view=runs`: every run as a table, `?status=` and `?workflow=` filtering it |
| [`route.tsx`](route.tsx)      | Layout for `/workflows`, with no component: sets the "Workflows" breadcrumb and page title                                                                                                                                                                                                                                                                                                                                          |
