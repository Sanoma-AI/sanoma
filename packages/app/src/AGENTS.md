# packages/app/src

The source of `@sanoma/app`: a TanStack Start app (routes, components, server functions) plus `startApp`, the Node entry that serves its build from a Sanoma config.

## Contents

| Path                                   | What it is                                                                                                                        |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| [`components/`](components/AGENTS.md)  | React components: page chrome, shared display pieces, graph and source panels                                                     |
| [`form/`](form/AGENTS.md)              | The start form, built from a workflow's input JSON Schema                                                                         |
| [`graph/`](graph/AGENTS.md)            | Builds and lays out the run and outline graphs, with no React                                                                     |
| [`hooks/`](hooks/AGENTS.md)            | React hooks added by the shadcn CLI                                                                                               |
| [`lib/`](lib/AGENTS.md)                | Small helpers shared by components and graph code                                                                                 |
| [`routes/`](routes/AGENTS.md)          | File routes: the pages and the `/api` JSON API                                                                                    |
| [`server/`](server/AGENTS.md)          | Server-only code behind the API routes and server functions                                                                       |
| [`index.ts`](index.ts)                 | The package entry: `startApp`, which checks the config, builds the context and serves the build                                   |
| [`start.ts`](start.ts)                 | Start's global middleware: the actor resolver, CSRF and server-function errors                                                    |
| [`server.ts`](server.ts)               | The server bundle's entry, re-exporting Start's server entry                                                                      |
| [`router.tsx`](router.tsx)             | Creates the router and query client, one per request on the server                                                                |
| [`routeTree.gen.ts`](routeTree.gen.ts) | Route tree generated by TanStack Router                                                                                           |
| [`api.ts`](api.ts)                     | Types and zod schemas for the HTTP API and server functions, shared by server and browser                                         |
| [`functions.ts`](functions.ts)         | The page's reads and changes as server functions                                                                                  |
| [`queries.ts`](queries.ts)             | TanStack Query options for the config, files' sources, scenarios, credentials, runs, actor and drift reports, with poll intervals |
| [`middleware.ts`](middleware.ts)       | `withPrincipal` (server functions) and `withPrincipalRoute` (API routes): require a named actor for a change                      |
| [`context.ts`](context.ts)             | `AppContext` and the `ResolveActor` type that `startApp` hands every request                                                      |
| [`actor.ts`](actor.ts)                 | Browser-side actor name: stored in `localStorage` and shared through a React context                                              |
| [`default-actor.ts`](default-actor.ts) | The default `resolveActor`, reading the `x-sanoma-actor` header                                                                   |
| [`loopback.ts`](loopback.ts)           | The loopback rule and the 403 for requests whose Host is not this machine                                                         |
