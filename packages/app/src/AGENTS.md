# packages/app/src

The source of `@sanoma-ai/app`: a TanStack Start app (routes, components, server functions) plus `startApp`, the Node entry that serves its build from a Sanoma config.

## Contents

| Path                                       | What it is                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`components/`](components/AGENTS.md)      | React components: page chrome, shared display pieces, graph and source panels                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| [`form/`](form/AGENTS.md)                  | The start form, built from a workflow's input JSON Schema, and a site's `RunForm` over it                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| [`graph/`](graph/AGENTS.md)                | Builds and lays out the run and outline graphs, with no React                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| [`hooks/`](hooks/AGENTS.md)                | React hooks added by the shadcn CLI                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| [`lib/`](lib/AGENTS.md)                    | Small helpers shared by components and graph code                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| [`routes/`](routes/AGENTS.md)              | File routes: the pages                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| [`server/`](server/AGENTS.md)              | Server-only code behind the server functions                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| [`index.ts`](index.ts)                     | The package entry: `startApp`, which checks the config, builds the context and serves the build, or with `dev` the dev server                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| [`build.ts`](build.ts)                     | `@sanoma-ai/app/build` (Node only): `appViteConfig`, the package's build and a company's with its sites; `buildApp` into `.sanoma/app/build/<key>`; `appDevServer`, the dev server over the same config with the dev-only plugins; `writeSiteFiles` (with `.sanoma/content.ts`), `sitesOf`, `appSources`; the `sanoma:content` plugin; `readContent`, `contentTypes` and `CONTENT_TYPES` from `content-files.ts`                                                                                                                                                                                                  |
| [`site.ts`](site.ts)                       | `@sanoma-ai/app/site`, which `sanoma/site` re-exports, shipped as source: what a site imports, `defineSite`, the app's router's `Link`, `Outlet`, hooks, `redirect` and `notFound` (not `createFileRoute`), and `api` over `callFn` with the types `.sanoma/api.ts` uses, `ApiError` and `errorBodyOf` for its refusals, and `content` with its types                                                                                                                                                                                                                                                             |
| [`api-client.ts`](api-client.ts)           | `createApi(transport)`: a site's `api` as a Proxy (the path joined with `.`, a new id per call or start, a workflow called as a function polled to its result), `Register`, `Api`, `UntypedApi`; imports no server function                                                                                                                                                                                                                                                                                                                                                                                       |
| [`content.ts`](content.ts)                 | A site's `content`: a Proxy whose `content.<kind>.list()` and `.get(slug)` import `virtual:sanoma/content` on the first call (a chunk of its own); `ContentSummary`, `ContentEntry`, `ContentKind`, `Content` (typed through `Register`)                                                                                                                                                                                                                                                                                                                                                                          |
| [`content-files.ts`](content-files.ts)     | Node only: `readContent`, the Markdown under `content/<kind>/` (front matter with `yaml`, HTML with `marked`, drafts, problems at their line), and `contentTypes`, the text of `.sanoma/content.ts`                                                                                                                                                                                                                                                                                                                                                                                                               |
| [`ui.ts`](ui.ts)                           | `@sanoma-ai/app/ui`, shipped as source: the kit a site imports, an explicit list of the shadcn components, the shared pieces (`Region`, `PageHeader`, `Facts`, badges, `Notice`, …), `useActor`, `useDensity` and `RunForm`                                                                                                                                                                                                                                                                                                                                                                                       |
| [`start.ts`](start.ts)                     | Start's global middleware: the actor resolver, CSRF and server-function errors                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| [`server.ts`](server.ts)                   | The server bundle's entry, re-exporting Start's server entry                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| [`router.tsx`](router.tsx)                 | Creates the router and query client, one per request on the server                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| [`style.css`](style.css)                   | The stylesheet: Tailwind, the theme's tokens (light, dark, effects, tones), and Compact's spacing                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| [`dev-imports.ts`](dev-imports.ts)         | The dev server's stand-in importer: a company file's React, TanStack and app imports on the server resolve from its id, to the app's copies                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| [`env.d.ts`](env.d.ts)                     | Ambient types (`vite/client`, Node) for a company's generated `.sanoma/app/tsconfig.json`, and the type of `virtual:sanoma/content`                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| [`routeTree.gen.ts`](routeTree.gen.ts)     | Route tree generated by TanStack Router for the package's own build; not shipped (a company's is `.sanoma/app/routeTree.gen.ts`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| [`api.ts`](api.ts)                         | Types and zod schemas for the server functions, shared by server and browser                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| [`functions.ts`](functions.ts)             | The page's reads and changes as server functions: the app's only HTTP surface; `callFn`, a site's `api`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| [`queries.ts`](queries.ts)                 | Query options for the config, sources, scenarios, credentials, the Permissions grid (`permissionsQuery`), runs (polled by `runsRefetchInterval`), a workflow's panel's (`workflowRunsQuery`) and each workflow's last (`lastRunsQuery`), the actor, drift and a collection's records (`recordsQuery`, through `api`); selectors such as `vendorsOf` (outside vendors only), `workflowTitles` and `usedBy` (with `siteCallers`, the sites' files that call something); the search schemas (`DataSearch`, `closeRecord`, and `listQueryOf`, what the grid asks `list`, with `enumFields`); `useStartRun`, `runLink` |
| [`middleware.ts`](middleware.ts)           | `withPrincipal`: requires a named actor for a server function that makes a change                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| [`context.ts`](context.ts)                 | `AppContext` that `startApp` hands every request, the `LoginProvider`, `ResolveActor` and `ServerEntry` types                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| [`actor.ts`](actor.ts)                     | Browser-side actor name: stored in `localStorage`, mirrored in the `sanoma_actor` cookie for the server's render, and shared through a React context with its groups as the server admits it                                                                                                                                                                                                                                                                                                                                                                                                                      |
| [`login/github.ts`](login/github.ts)       | `githubLogin`: GitHub's OAuth web flow at `/auth/github/*`, the login only (the people file admits), a signed session cookie; the cookie helpers `server/setup.ts` shares                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| [`login/admission.ts`](login/admission.ts) | `admitting`: wraps every login so only a declared person signs in, as declared (`admit`); the 403 page or `not_admitted` JSON for anyone else                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| [`login/page.ts`](login/page.ts)           | A login's small page of its own (`smallPage`), `escapeHtml`, and `wantsJson`: JSON for server functions and changes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| [`loopback.ts`](loopback.ts)               | `loopbackLogin` (the default: the `x-sanoma-actor` header, `actorFromHeader`, else the `sanoma_actor` cookie, `actorFromCookie`, on this machine only), Host names (`hostName`) and the 403 for requests whose Host is not this machine; which hosts are is `isLoopback` in `@sanoma-ai/workflows/shared`                                                                                                                                                                                                                                                                                                         |
