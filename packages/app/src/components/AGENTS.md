## Layout conventions

- Spacing scale: `gap-(--gap-region)` between a page's regions, `gap-(--card-spacing)` inside a card (Card's own variable), `gap-(--gap-section)` inside a section (a titled one is a `Region`), `gap-2` inside an item.
- Compact (`data-density="compact"` on `#app`, chosen under Density in the user menu) sets Tailwind's `--spacing` on the sidebar inset, which cards and every spacing utility follow, and re-sets `--gap-region` and `--gap-section`; see `src/style.css`. The `compact:` variant is for shape (the heights of the graph box and the Code card), plus a few deliberate extra cuts on top of the unit: the card headers' padding and `Facts`' row gap. Items follow the unit alone. The sidebar (its bar and panels) keeps the full unit, as its widths are fixed.
- A link drawn as a button is a `ButtonLink`, never `Button` with `render` (even with `nativeButton={false}`, as the shadcn skill shows): Base UI's Button makes it `role="button"` and lets Space press it. A tooltip is a `Tip` (or `TipButton` on an icon button), which also gives its trigger the tip as `aria-describedby`, since Base UI's tooltip does not.
- Every pane of a workflow's page is a [`WorkflowView`](workflow-view.tsx): its notices, the graph card beside the 20rem inspector (one column while the pane itself is narrower than `@3xl`), then the tabs.
