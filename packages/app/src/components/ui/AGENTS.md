# packages/app/src/components/ui

shadcn/ui components, added by the shadcn CLI as configured in [`components.json`](../../../components.json) (`base-nova` style, on Base UI primitives: a part takes `render`, not `asChild`), one file per component. They are the app's base controls, stock shadcn components: re-add one with the CLI rather than edit it. The look comes from [`style.css`](../../style.css)'s tokens; a component is edited only for what a token cannot say, and such an edit is re-applied after a re-add: controls 28 px high by default (`Button`, `Input`, `NativeSelect`, `Tabs`), a button's and a tab's label 12 px medium (a field keeps its value's 14 px), an outline button and bubble, the current tab and an input group on `card`, where upstream has `background` (the page's paper is no longer the card's colour), the overlay behind a dialog or sheet `bg-overlay`, the slider's thumb `bg-card`, an icon imported per file (`@phosphor-icons/react/dist/csr/<Name>`), an input group dimmed only by its own control (upstream's `has-disabled` takes any disabled button in it). An input group's addon focuses its control on a click when that is a textarea too, where upstream looks only for an input. The chat's `Message`, `Bubble`, `MessageScroller`, `Trace`, `CodeBlock`, `Marker` and `InputGroup` are those of shadcn's AI Elements patterns; `.agents/skills/shadcn/rules/chat.md` says how they compose. The app's own components in the parent directory compose them.
