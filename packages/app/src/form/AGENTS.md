# packages/app/src/form

The start form: it turns a workflow's input JSON Schema into form fields and renders them, empty for a live run or filled read-only with a scenario's input for a sandbox run. The server still validates the input, so the form only shapes entry. `RunForm` is the same form for a site, by the workflow's name, and a collection's record form (`components/record-form.tsx`) and a declaration's (`components/declaration-form.tsx`) are drawn by its pieces.

## Contents

| Path                               | What it is                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`schema.ts`](schema.ts)           | Reads a JSON Schema into field descriptions: scalars (a person by `format: "person"`, a date by `format: "date"`, as a collection marks them), enums, one level of nesting, JSON fallback; the form's starting values, from defaults or a given input (`initialValues`), date-times as ISO text, and the input it sends                                                                                                                                                                                          |
| [`start-form.tsx`](start-form.tsx) | TanStack Form that renders those fields (a date-time, `DateTimeInput`, as ISO text on the server, then in the browser's time zone; a date as a date input; a person as their id) and starts the run, or with a scenario shows its input in a disabled fieldset and starts a sandbox run of it; the pieces a record form shares: `useSchemaForm`, `FieldView`, `FormFoot` and `errorsOf` (a refusal's issues on their fields)                                                                                     |
| [`run-form.tsx`](run-form.tsx)     | `RunForm({ workflow })`, exported by `@sanoma-ai/app/site` (`sanoma/site`, not the kit: it reads the config and starts a run; its pieces come from `components/kit.tsx`, not `common.tsx`, whose sites list would import every `site.ts` and so `sanoma/site` again): the workflow looked up in the config, `StartForm` for a live run under its title linking to its page and the will-ask line, and, once started (`onStarted`), a link to the run instead of opening it; a notice for a name the config lacks |
| [`will-ask.tsx`](will-ask.tsx)     | `WillAsk({ workflow })`: what the policy will do on a run you start, ahead of it (`previewQuery`, once per actor and workflow; the words are `willAsk` in `lib/preview.ts`), on `RunForm` and New run                                                                                                                                                                                                                                                                                                            |
