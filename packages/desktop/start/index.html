Sanoma

Open the folder a company lives in, start a new one in an empty folder, or clone one from GitHub. Sanoma installs its packages and starts it on this computer, in a window of its own. Closing that window leaves the company running; Quit stops it.

A public repository, or one this Mac's keychain can sign in to. Next, choose where it goes.

Who makes the changes? git signs each change with a name and an email address.

Saving sets them for every git repository on this computer (git config --global).
