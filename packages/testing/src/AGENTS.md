# packages/testing/src

Source of `@sanoma-ai/testing`: the test worker helpers exported from the package root, the vitest test app exported as `@sanoma-ai/testing/harness`, the msw replay helper exported as `@sanoma-ai/testing/replay`, the scenario helpers exported as `@sanoma-ai/testing/scenarios`, a connector's feature tests exported as `@sanoma-ai/testing/features`, and the host and wakeup kits exported as `@sanoma-ai/testing/host` and `@sanoma-ai/testing/wakeup`.

## Contents

| Path                           | What it is                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`index.ts`](index.ts)         | `testDatabaseUrl`, `withFake` and `startTestWorker` (on a required `databaseUrl`), `ensureBuilt` and `waitFor` (from `build.ts`), and the `Fake` types                                                                                                                                                                                                                                                                    |
| [`build.ts`](build.ts)         | `ensureBuilt` (a package's build, when its outputs are stale) and `waitFor` (polling), exported from the root                                                                                                                                                                                                                                                                                                             |
| [`features.ts`](features.ts)   | `describeFeatures` registers a vitest test per scenario of a connector's `features/`, on its fake and on its driver (replayed, live or recording), over `testFeature` from `@sanoma-ai/workflows/scenario`                                                                                                                                                                                                                |
| [`host.ts`](host.ts)           | The host conformance kit (`checkHost`, `hostCheck`, `hostCheckWorkflows`), `fakeHost` (in this process, long-lived or behind a proxy that starts it again once stopped), `inProcessHost` (a supervised worker, answering `/healthz` and `/wake`), `testRepository` (a bare git repository as a host's source), `throughWorkflows` (a host's apply and drift through the built-ins), `dockerAvailable`; the `./host` entry |
| [`harness.ts`](harness.ts)     | `useTestApp`: a worker, a `SanomaClient` and a raw `DBOSClient` for a `describe`, with `restart()` on the same ledger                                                                                                                                                                                                                                                                                                     |
| [`replay.ts`](replay.ts)       | `replay(options)`: serves a vendor's recorded exchanges through msw, and records new ones with `SANOMA_RECORD=1`                                                                                                                                                                                                                                                                                                          |
| [`scenarios.ts`](scenarios.ts) | `describeScenarios` registers a vitest test per scenario in a config, over `runScenario` from `@sanoma-ai/workflows/scenarios`, re-exported                                                                                                                                                                                                                                                                               |
| [`wakeup.ts`](wakeup.ts)       | The wakeup conformance kit (`checkWakeup`, `wakeupCheckWorkflows`: the host checks' and a tick every minute), `fakeWakeup` (with the registrations it took) and `fakeWakeupType` (`testwakeup.timer`, a timer in this process that sends `/wake` to the host it names); the `./wakeup` entry                                                                                                                              |
