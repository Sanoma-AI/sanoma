# packages/bridge/src

Source of `@sanoma/bridge`: the client exported from the package root, the connector fake and the recorded replies it serves, exported as `@sanoma/bridge/fake`, the generic connector as `@sanoma/bridge/connector`, and the generator and state conversions as `@sanoma/bridge/tfschema`.

## Contents

| Path                              | What it is                                                                                                                                                           |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`index.ts`](index.ts)            | The package root: `startBridge`, `readPins`, `BridgeError`, `parseSchema` and the types                                                                              |
| [`bridge.ts`](bridge.ts)          | The `Bridge` interface, `ProviderRef`, `ResourceState`, `Diagnostic`, `BridgeError`, and `bridgeClient`, which maps a Connect client's messages and errors onto them |
| [`connector.ts`](connector.ts)    | `tfConnector`: an OpenTofu connector (resource types, connector, driver) from the generated types; the `./connector` entry                                           |
| [`tffake.ts`](tffake.ts)          | `tfFake`: a connector's fake, its driver over a `stateBridge`, with `put`, `override` and `remove`                                                                   |
| [`configure.ts`](configure.ts)    | `ensureConfigured`: configures a provider once per bridge and config, serialized, and again after it has gone                                                        |
| [`replies.ts`](replies.ts)        | `loadReplies` and `stateBridge`: recorded replies as mutable state, and a bridge over it, for connectors' fakes                                                      |
| [`client.ts`](client.ts)          | `startBridge`: spawns `provider-bridge serve`, waits for the ready line, connects over the unix socket                                                               |
| [`fake.ts`](fake.ts)              | The `./fake` entry: re-exports `tfFake`, `loadReplies`, `stateBridge`, `fixturesDir` and their types                                                                 |
| [`fixtures.ts`](fixtures.ts)      | The fixture format and paths, shared by `loadReplies`, the tfschema CLI and the test helpers (`../test/fake-bridge.ts`, `../test/record.ts`)                         |
| [`schema.ts`](schema.ts)          | `SchemaDocument` and its types, `parseSchema`                                                                                                                        |
| [`pins.ts`](pins.ts)              | `readPins`, and the path of `testdata/`                                                                                                                              |
| [`json.ts`](json.ts)              | `isObject` and `blockOf`, shared by the generator, the state conversions and the test recorder                                                                       |
| [`tfschema.ts`](tfschema.ts)      | The `./tfschema` entry: re-exports `tfschema/` without its CLI                                                                                                       |
| [`tfschema/`](tfschema/AGENTS.md) | OpenTofu provider schemas to zod: the generator of `resources.gen.ts`, its CLI, and the state conversions                                                            |
| [`gen/`](gen/)                    | Generated by `pnpm run generate` from `proto/`; never edited by hand                                                                                                 |
