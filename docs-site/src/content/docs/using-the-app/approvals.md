1. Open **Inbox → For you**. Select the request to see who started the run and which operations the approval covers.
2. Read the request details. Choose **Approve** or **Reject** and add a note if you want to record your reason.
3. Once the run reads your decision, the request leaves the pending list. Open **Decided** to find it again, or [inspect the run](/using-the-app/runs/#inspect-a-run) to see what happened next.

If the request appears only under **Everyone**, check [who can decide an approval](/workflows/approvals/#who-approves).

## Inbox

**For you** lists pending requests you may decide. **Everyone** includes requests waiting on someone else. Select a row to read the request and see who started the run.

If the worker is offline when you decide, Sanoma shows the decision as queued. The run reads it when the worker resumes. **Decided** shows decisions from the latest 50 runs. **Decided today** uses midnight in your browser’s time zone.
